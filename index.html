01

ภาพรวมแผน

💡 วิเคราะห์จากผลวิ่ง Half 2:06

Split ช่วงท้ายเร่งได้ถึง 5:21/km = ยังมีแรงเหลือ endurance ดีมาก. Riegel ทำนายมาราธอนได้ถึง ~4:22 แต่เพราะเป็นการก้าวสู่ระยะมาราธอน (ไกลกว่า Half เท่าตัว) เราตั้งเป้า Sub 4:45 ที่ท้าทายแต่ปลอดภัย เน้นจบอย่างแข็งแรงและสนุก.

แผน 19 สัปดาห์ แบ่ง 4 เฟส ยึดหลัก 3:1 (หนัก 3 · ลด 1). โครงสัปดาห์: จันทร์พัก · อังคาร speed เบา · พุธ easy · พฤหัส tempo/MP · ศุกร์ strength · เสาร์ easy+strides · อาทิตย์ long run.

เฟส 1 · Base (W1-6)

สร้างฐาน endurance · long run 14→22km · ปรับตัวเข้าระยะไกล · speed เบา

เฟส 2 · Build (W7-11)

เพิ่ม volume + เริ่ม MP · long run ถึง 28km · tempo ยาวขึ้น

เฟส 3 · Peak (W12-15)

long run ไกลสุด 30-32km · MP practice · ซ้อม fueling วันแข่ง

เฟส 4 · Taper (W16-19)

ลด volume ให้ร่างกายสด · รักษาความคุ้น pace · พร้อมแข่ง

02

โซน & เพซ

เพซคำนวณจากเป้า Sub 4:45 (MP 6:45). งานเบาดู HR · งานเร็วดู pace · long run คุมช้าๆ Zone 2.

03

ตาราง 18 สัปดาห์

กดแต่ละสัปดาห์เพื่อดู 6 วัน (จันทร์พัก). Long run ไต่: 14→16→18→12→20→22→24→16→26→28→30→20→32→race prep. ตัวหนา = deload.

04

วิธีแล่นแต่ละวัน

ทุก session: warm-up jog 10 นาที + strides → เนื้อหลัก → cool-down + ยืด.

🏁 กลยุทธ์วันแข่ง (มาราธอนแรก)
  1. km 1-10: ออกช้ากว่าเป้า อย่าตื่นเต้นออกเร็ว (บทเรียนจาก Half—เจ้าเร่งจบได้ = เก็บแรงไว้ท้ายเป็น!)
  2. km 11-30: ล็อกเพซเป้าให้นิ่ง · ดื่มน้ำทุกจุด · Gel ทุก 40 นาที
  3. km 31-42: ช่วงพิสูจน์ใจ · ค่อยๆ ไป ถ้าแรงเหลือค่อยเร่ง
  4. อากาศ Bangsaen ร้อน → ถ้าเหนื่อยเกิน ถอยเป้า A ได้ จบอย่างแข็งแรงสำคัญสุด
06

เคล็ดลับ

🎯 80/20

~80% แล่นเบา (Zone 2) · ~20% หนัก. Easy ต้องเบาจริง—ช้าจนคุยได้สบาย นั่นแหละถูก.

🏃 มาราธอนแรก

ไกลกว่า Half เท่าตัว—long run คือกุญแจ. อดทนไต่ทีละนิด อย่าข้ามขั้น. เป้าคือจบอย่างสนุกและแข็งแรง.

🍚 Fueling

Long run 90 นาที+ เริ่ม Gel ทุก 40 นาที. ฝึกกินในซ้อมให้ท้องชิน. Carb-load 2-3 วันก่อนแข่ง.

💪 Strength

วันศุกร์: squat, lunge, glute bridge, core, calf raise. ป้องกันบาดเจ็บ + รักษาฟอร์มตอนล้า.

⏱️ HR vs Pace

Easy/Long → ดู HR (กันเผลอเร็ว). วันร้อน/ล้า เชื่อ HR มากกว่า pace.

🛌 ฟื้นตัว

นอนให้พอ · deload สำคัญ · เจ็บให้พัก. ฟังร่างกายมากกว่าตัวเลข—สม่ำเสมอชนะหักโหม.
