01

ภาพรวมแผน

💡 วิเคราะห์ใหม่ — มาราธอนที่ 2 (PR 5:51 · 2025)

Half 2:06:05 (เร่งจบ 5:21 = แรงเหลือ) ทำนายมาราธอนได้ถึง ~4:22 แต่ผลจริงครั้งแรกคือ 5:51 — ช่องว่าง ~1.5 ชม. บอกชัดว่าปัญหาไม่ใช่ความฟิต แต่คือการ execute ระยะ full (พลังงานหมด / ออกเร็ว / อากาศร้อน — ลองทบทวนว่า km 30+ ครั้งนั้นเกิดอะไร แล้วซ้อมแก้ตรงนั้น). แผนนี้แก้ตรงจุด: fueling เป็นระบบ + วินัยเพซ + MP ท้าย long run. แม้ถอยไปเป้า A (5:00) ก็ยังทำลาย PR เกือบชั่วโมง.

⏱️ หัวใจของแผนนี้ — คุม long run ด้วย "เวลา" ไม่ใช่ "ระยะ"
  • เพซ long run ของเธอ ~7:00-7:20 → 32km = 3 ชม. 44 นาที บนขา (นานเกินไป!)
  • เพดานปลอดภัย = ไม่เกิน ~3:15-3:20 ชม. — มาราธอนที่ 2 ก็จริง แต่ base ระยะไกลยังต้องสร้างใหม่
  • แผนนี้จึงจบที่ 28km ≈ 3:16 ชม. — ได้ประโยชน์เต็ม แต่ไม่พังร่างกาย
  • เพิ่ม "คุณภาพ" (ใส่ MP ท้าย long) แทนการเพิ่มระยะ · ทุกสัปดาห์แสดงเวลาบนขาให้เห็น
⚠️ อ่านก่อนเริ่ม — เช็ค volume ปัจจุบัน
  • ปรับตามฐานจริง (ตอนนี้วิ่ง 45-55 km/wk): W1 เริ่ม ~40 km — ต่ำกว่าฐานเดิมเล็กน้อยเพราะเพิ่ม quality เข้ามาพร้อมกัน · เกินฐานเดิมตั้งแต่ W6-W7 · peak สูงสุด 64 km/wk (W11-W14) ≈ 7.7 ชม./สัปดาห์
  • volume เพิ่มที่ easy วันพุธ+เสาร์เท่านั้น — long run ยังติดเพดานเวลา ~3:15-3:20 ชม. เท่าเดิม · deload weeks คงต่ำไว้ตามเดิม
  • กฎเหล็ก: เพิ่ม volume ไม่เกิน +10%/สัปดาห์ — แผนนี้คุมไว้แล้วทุกสัปดาห์
  • Cut-off rule: เจ็บ >3/10 หรือเจ็บแหลมเฉพาะจุด (ข้อ/เอ็น/กระดูก) → เปลี่ยน quality/long วันนั้นเป็น Easy สั้นหรือพักทันที · ตารางคือแนวทาง ไม่ใช่คำสั่ง

โครงสัปดาห์: จันทร์พัก · อังคาร speed เบา · พุธ easy · พฤหัส tempo/MP · ศุกร์ strength · เสาร์ easy+strides · อาทิตย์ long run. ยึดหลัก 3:1 (หนัก 3 สัปดาห์ · ลด 1 สัปดาห์).

W1-3 (+ deload W4)

เฟส 1 · Base

สร้างฐาน endurance · long 12→16km · ปรับตัวเข้าระยะไกล · speed เบา · tempo สั้น.

W5-7 (+ deload W8)

เฟส 2 · Build

เริ่ม MP run · long ถึง 22km (2:32 ชม.) · tempo ยาวขึ้น · volume แตะ 59 km/wk.

W9-11 (+ deload W12)

เฟส 3 · Peak 1

long 24→26km · MP run 9-10km · เริ่มใส่ MP ท้าย long run · volume 64 km/wk.

W13-15

เฟส 4 · Peak 2

🎯 W14 = long run ไกลสุด 28km (≈3:16 ชม.) last 8km MP + ซ้อม fueling เต็มรูปแบบ — 4 สัปดาห์ก่อนแข่ง.

W16-17

เฟส 5 · Taper

ลด volume 64 → 41 → 30 km/wk. รักษาความคุ้นเพซ MP · ขาสดขึ้นทุกวัน.

W18 · 9-15 พ.ย.

เฟส 6 · Race Week

วิ่งเบาสั้นๆ + strides · ศุกร์-เสาร์พักเต็ม ไม่ยกเวท · Carb-load · อาทิตย์ 15 พ.ย. = RACE DAY 🏆

02

โซน & เพซ

คำนวณจากเป้า Sub 4:45 (MP 6:45) และ Half PR 5:58/km. สังเกต: tempo เร็วกว่าเพซ Half เล็กน้อย — เพราะ threshold คือเพซที่ยืนได้ประมาณ 60 นาที.

❤️ Heart Rate Zones

ยังไม่มีค่า Max HR / LT จริง — ใช้ % ของ Max HR + talk test ไปก่อน. ใส่ตัวเลข bpm จริงเมื่อทดสอบแล้ว.

โซน% Max HRความรู้สึก (talk test)ใช้กับ
🔬 หาค่า HR จริง — อย่าใช้สูตร 220 − อายุ
  1. สูตร 220 − อายุ คลาดเคลื่อนได้ ±10-12 bpm → zone ผิดทั้งชุด
  2. ถ้ามีนาฬิกา Garmin: ทำ Lactate Threshold test → ได้ LT bpm + LT pace จริง
  3. หรือดูจากการแข่ง: HR เฉลี่ยตอนแข่ง Half ≈ LT (บวกลบเล็กน้อย)
  4. ระหว่างนี้เชื่อ talk test เป็นหลัก — เบา = คุยได้เป็นประโยค
03

ตาราง 18 สัปดาห์

กดแต่ละสัปดาห์เพื่อดูครบ 7 วัน. Long run (เวลาบนขา): 12→14→16→10→18→20→22→14→24→25→26→16→26→28 (3:16 ชม.)→22→16→10→🏆 · ตัวหนา = deload/longest · ทุก long run ≤ 3:20 ชม.

วิธีแล่นแต่ละวัน

ทุก session: warm-up jog 10 นาที → เนื้อหลัก → cool-down jog 5-10 นาที + ยืดเหยียด.

🏁 กลยุทธ์วันแข่ง (มาราธอนที่ 2 — แก้เกมจากครั้งแรก)
  1. km 1-10: ออกช้ากว่าเป้า 5 วิ/km · อย่าตื่นเต้นออกเร็ว
  2. km 11-30: ล็อกเพซเป้าให้นิ่ง · ดื่มน้ำทุกจุด · Gel ทุก 30 นาที (เป้า 45-60g คาร์บ/ชม.) + เกลือแร่ (เริ่มตั้งแต่ km 8)
  3. km 31-42: ช่วงพิสูจน์ใจ · จุดแข็งของเธอคือเร่งจบ (Half จบ 5:21!) — เก็บแรงไว้ตรงนี้
  4. อากาศ Bangsaen ร้อน → เหนื่อยเกินถอยเป้า A (5:00) ได้เสมอ — แม้เป้า A ก็ยังทำลาย PR ~51 นาที ทุกเส้นทางคือชัยชนะ
06

เคล็ดลับ

⏱️ เวลา > ระยะ

สำหรับ long run สิ่งที่ร่างกายรับรู้คือ เวลาบนขา ไม่ใช่ตัวเลขกิโล. 28km ที่เพซเธอ = 3:16 ชม. เท่ากับ 34km ของนักวิ่งเร็ว. อย่าเทียบระยะกับคนอื่น.

🎯 80/20

~80% แล่นเบา (Zone 2) · ~20% หนัก. Easy ต้องเบาจริง — ช้าจนคุยเป็นประโยคได้ นั่นแหละถูกแล้ว.

🎯 แก้เกมจากครั้งแรก

ครั้งแรก 5:51 ทั้งที่ Half บอก ~4:22 — สิ่งที่หายไปคือช่วงท้าย ไม่ใช่ความเร็ว. คราวนี้: fueling เป็นระบบ + ออกช้า + MP ท้าย long run. long run สม่ำเสมอทุกสัปดาห์คือกุญแจ.

🍚 Fueling

Long run 90 นาที+ เริ่ม Gel ทุก 30 นาที (เป้า 45-60g คาร์บ/ชม.) + เกลือแร่ (อย่ารอหิว). ฝึกกินในซ้อมให้ท้องชิน — W14 คือการซ้อมใหญ่. Carb-load 2-3 วันก่อนแข่ง.

💪 Strength (ศุกร์)

Squat · Lunge · Glute Bridge · Core · Calf Raise. ป้องกันบาดเจ็บ + รักษาฟอร์มตอนล้า km 30+. สัปดาห์แข่งงดทั้งหมด.

🛌 ฟื้นตัว

นอนให้พอ · deload คือส่วนสำคัญของแผน ไม่ใช่ขี้เกียจ · เจ็บให้พัก. สม่ำเสมอชนะหักโหมเสมอ.
